# How to Make This Website Yours

This website is made from editable files. You cannot permanently change it from the preview screen alone. You need to open the files in an editor or edit them directly on GitHub.

## Edit words on GitHub

1. Open this repository.
2. Open `index.html`.
3. Tap the pencil icon.
4. Change the words you want.
5. Tap **Commit changes** to save.

## Change a picture

1. Upload your picture into an `assets/photos` folder.
2. Open `index.html`.
3. Find the picture you want to replace. It looks like this:

```html
<img src="https://images.unsplash.com/..." alt="Description">
```

4. Replace the link with your own picture path:

```html
<img src="assets/photos/my-picture.jpg" alt="Portrait photographed by Alain Marley">
```

Use simple file names without spaces, such as `portrait-1.jpg` or `downtown-erie.jpg`.
